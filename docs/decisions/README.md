# Decision Records (ADRs)

Este directorio está reservado para los **Architecture Decision Records (ADRs)** formales del proyecto.

De acuerdo con los principios de la **Fase 0 (Descubrimiento y Fundación)**, las decisiones arquitectónicas y tecnológicas concretas (selección de stack, librerías específicas, proveedores de autenticación, motores de renderizado) se encuentran actualmente identificadas como **Decisiones Abiertas (`OPEN DECISIONS`)** en la documentación de:

- [`PRODUCT_FOUNDATION.md`](../product/PRODUCT_FOUNDATION.md#11-open-decisions)
- [`ARCHITECTURE_PRINCIPLES.md`](../architecture/ARCHITECTURE_PRINCIPLES.md#6-open-decisions)
- [`SECURITY_PRINCIPLES.md`](../security/SECURITY_PRINCIPLES.md#9-open-decisions)

A medida que el equipo de arquitectura y el usuario validen y cierren cada decisión estratégica en las fases sucesivas, se formalizarán aquí siguiendo la plantilla estándar ADR (Contexto, Decisión, Estado, Consecuencias).
