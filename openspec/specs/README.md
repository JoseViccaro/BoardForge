# OpenSpec — System Specifications (`openspec/specs/`)

This directory contains functional, technical, and architectural domain specifications for BoardForge.

## Bounded Context Specs (Planned / Evolving)
- `iam.spec.md`: Identity & Access Management, multi-tenant organizations, memberships, RBAC/ABAC.
- `catalog.spec.md`: Hardware devices, PCB models, manufacturers, revisions, and optical overlays.
- `boardview.spec.md`: CAD/BRD/BDV canonical schema, WebGL/Canvas rendering pipeline, pad/pin/via/net topologies.
- `schematics.spec.md`: PDF/SVG vector extraction, coordinate spatial mapping, bidirectional cross-probing.
- `measurements.spec.md`: Diode mode readings, ground resistance, power rail states, diagnostic decision trees.
- `repair-knowledge.spec.md`: Known issues repository, procedural troubleshooting guides, board history logs.
- `security.spec.md`: OWASP ASVS L2 verification controls, file ingestion pipeline, RGPD data erasure protocols.
